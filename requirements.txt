# Tools Included

## Port Scanner

A Python-based network scanning tool demonstrating port analysis concepts.

Evaluates password security using password complexity checks.

Uses hashing techniques to identify unauthorized file modifications.

## Log Analyzer

Reviews security logs and detects suspicious events.
